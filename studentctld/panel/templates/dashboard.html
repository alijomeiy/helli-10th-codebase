آزمایشگاه بعد از حدود ۳۰ دقیقه بی‌کاری خودش خوابید تا منابع سرور آزاد بماند؛ کارهای شما محفوظ می‌ماند.

نحوه اتصال از کلاینت SSH (ترمینال، VSCode، PuTTY)

۱. پورت استاندارد (اینترنت خانه یا شبکه آزاد): 
ssh {{ current_user.username }}@{{ config.SERVER_DOMAIN }} -p 22
۲. پورت ۲۲۲۲ (مخصوص اینترنت مدرسه در صورت انسداد پورت ۲۲): 
ssh {{ current_user.username }}@{{ config.SERVER_DOMAIN }} -p 2222
۳. در صورت بروز مشکل در DNS با نشانی مستقیم IP سرور: 
ssh {{ current_user.username }}@62.3.41.38 -p 2222

سپس یک سرویس روی پورت اختصاصی خودتان اجرا کنید، مثلاً:

python3 -m http.server {{ current_user.port }}

و در مرورگر باز کنید: http://{{ config.SERVER_DOMAIN }}:{{ current_user.port }}/
