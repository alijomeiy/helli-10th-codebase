# راهنمای مسابقه CTF (CTFd)

## معماری

- **CTFd** پشت nginx روی `https://ctf.helli-10th-computer.ir` اجرا می‌شود
  (داکر: CTFd + MariaDB + Redis — حدود ۱GB رم). پورت 8000 فقط روی خود سرور
  (loopback) در دسترس است و در فایروال بسته شده.
- چالش‌ها **داخل حساب لینوکسی خود دانشجوها** پنهان شده‌اند؛ هر دانشجو پرچم
  یکتای خودش را دارد (`FLAG{username-xxxxxx}`) پس دور زدن با کپی‌کردن پرچم
  تیم دیگر ممکن نیست.
- ۱۰ چالش در ۴ سطح: لینوکس ۱ (۳×۱۰۰)، لینوکس ۲ (۳×۱۵۰)، لینوکس ۳ (۲×۲۰۰/۲۵۰)،
  وب (۲×۱۵۰ — اختیاری). راهنمایی هر چالش امتیاز دارد.
- حالت تیمی: هر تیم ۲-۳ نفر با یک کامپیوتر؛ در CTFd یک «تیم» می‌سازند.

## نصب یک‌باره

```bash
sudo apt install -y python3-requests
cd ~/helli-10th-codebase/studentctld/ctf
cp .env.example .env
# مقادیر .env را عوض کنید:
#   SECRET_KEY=$(openssl rand -hex 32) و رمزهای دیتابیس
nano .env

./classroom.sh start          # بالا آمدن CTFd
# nginx: قالب ctf.conf.template در deploy/nginx/templates/ از قبل موجود است؛
# بعد از هر بازسازی کانتینر nginx به‌صورت خودبار بارگذاری می‌شود.
```

سپس در مرورگر `https://ctf.helli-10th-computer.ir` را باز کنید و ویزارد اولیه را کامل کنید:

1. **Setup Mode**: `Teams Mode` را انتخاب کنید.
2. کاربر مدیر (admin) بسازید و ایمیل/نام دلخواه بدهید.

## ساخت توکن API و راه‌اندازی مسابقه

1. به‌عنوان admin وارد شوید → صفحه‌ی **Settings → Access Tokens** → توکن بسازید.
2. روی سرور:

```bash
cd ~/helli-10th-codebase/studentctld/ctf
sudo CTFD_TOKEN=<توکن> ./run_contest.sh
./classroom.sh backup     # اسنپ‌شات تمیز برای ریست بین کلاس‌ها
```

اسکریپت پرچم‌ها را در خانه‌ی همه‌ی دانشجوها می‌پاشد و چالش‌ها را با همه‌ی
پرچم‌ها و راهنمایی‌ها در CTFd می‌سازد (اجرای دوباره‌اش بی‌خطر است).

## مدیریت هر کلاس

| کار | دستور |
|---|---|
| شروع کلاس | `./classroom.sh start` |
| پایان کلاس | `./classroom.sh stop` |
| وضعیت | `./classroom.sh status` |
| ریست کامل بین کلاس‌ها (پاک‌شدن تیم‌ها و حل‌ها) | `./classroom.sh reset` |

جدول امتیازات: `https://ctf.helli-10th-computer.ir/scoreboard` (عمومی و زنده)

## دانشجوها چطور شرکت می‌کنند؟

1. یکی از اعضای تیم با حساب لینوکسی خودش SSH می‌زند — پرچم‌ها همان‌جاست.
2. در CTFd ثبت‌نام می‌کنند / تیم می‌سازند.
3. چالش را در CTFd می‌خوانند → در SSH حل می‌کنند → پرچم را در CTFd ثبت می‌کنند.

نکته: چون هر دانشجو پرچم خودش را دارد، ادمین از صفحه‌ی Submissions می‌تواند
ببیند پرچمِ چه کسی ثبت شده (ردپای حل کردن).

## نکات

- **نکته‌ی مهم برای فراخوانی API با توکن**: CTFd فقط وقتی هدر
  `Authorization: Token ...` را قبول می‌کند که درخواست هدر
  `Content-Type: application/json` هم داشته باشد (حتی برای GET و DELETE).
- چالش‌های «وب» نیاز دارد `public_html` دانشجو از وب در دسترس باشد
  (تنظیم nginx ساب‌دامین) یا حداقل با مرورگر فایل را باز کنند
  (`about.html` را می‌توان مستقیم هم باز کرد).
- رم مصرفی کل استک CTF حدود ۶۰۰MB–۱GB است؛ با پنل و حساب‌های دانشجو
  در ۸GB جا می‌شود.
- بین کلاس‌ها حتماً `reset` بزنید وگرنه تیم‌های کلاس قبل در جدول می‌مانند.
