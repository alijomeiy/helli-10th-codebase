📜 آموزش اسکریپت bash مقدماتی

هر چیزی که در ترمینال می‌زنید، می‌شود یک فایل که همیشه اجرا شود.

اسکریپت = فایل متنی از دستورها

خط اول shebang است: به لینوکس می‌گوید «این فایل را با چه برنامه‌ای اجرا کن»:

#!/bin/bash
echo "Hello, $USER!"

بعد دو مرحله: اجازه‌ی اجرا بده و اجرا کن:

chmod +x myscript.sh
./myscript.sh

بدون chmod +x با bash myscript.sh هم می‌شود اجرا کرد.

متغیرها

name="Amir"              # توجه: دور = فاصله ممنوع!
echo "Salam $name"       # استفاده با $
echo "Folder: ${name}s"  # وقتی متن می‌چسبد، با {} جدا کن
files=$(ls | wc -l)      # خروجی یک دستور → متغیر (جایگزینی دستور)
echo "We have $files files"

ورودی: آرگومان و read

#!/bin/bash
echo "First: $1, Second: $2"    # ./s.sh a b
echo "All: $@"                  # همه‌ی آرگومان‌ها
read -p "Esmet chiye? " uname   # گرفتن از کاربر
echo "Salam $uname"

شرط: if

if [ "$1" = "hi" ]; then
  echo "Hi there!"
elif [ -z "$1" ]; then        # -z یعنی خالی
  echo "Say something!"
else
  echo "You said: $1"
fi
آزمونمعنی
[ -f f ]فایل وجود دارد؟
[ -d d ]پوشه وجود دارد؟
[ -z "$x" ]خالی است؟
[ "$a" = "$b" ]متن‌ها برابرند؟
[ $n -gt 5 ]عددی بزرگ‌تر؟ (lt/le/ge/gt/eq/ne)
فاصله‌های اجباری: دور [ ] و دور = باید فاصله باشد: [ "$a" = "b" ] درست، ["$a"="b"] غلط!

حلقه: for

for i in 1 2 3; do
  echo "Round $i"
done

for f in /var/log/*.log; do         # روی همه‌ی لاگ‌ها
  echo "$f : $(wc -l < "$f") lines"
done

for i in $(seq 1 5); do echo "N=$i"; done

وضعیت خروج

ls /nope
echo $?         # غیر صفر = شکست
ls /etc > /dev/null
echo $?         # 0 = موفق

اسکریپت شما هم می‌تواند وضعیت برگرداند: exit 0 (موفق) یا exit 1 (شکست) — همین است که cron و ابزارها را از موفقیت کارتان خبردار می‌کند.

خواندن اسکریپت دیگران (مهم‌ترین مهارت!)

بیشتر وقت‌ها لازم نیست بنویسید — باید بفهمید چه می‌شود. از بالا به پایین بخوانید؛ متغیرها را جایگزین کنید؛ هر دستور را انگار در ترمینال می‌زنید دنبال کنید. اسکریپت‌های چالش‌های کلاس هم همین‌طور خوانا هستند.

تمرین (در آزمایشگاه خودتان انجام دهید)

  1. اسکریپتی بنویسید که تاریخ و نام کاربر و تعداد فایل‌های home را چاپ کند.
  2. اسکریپتی بنویسید که یک نام فایل بگیرد ($1) و بگوید وجود دارد یا نه.
  3. با for، پنج پوشه‌ی /tmp/b$i بسازید و بعد همه را پاک کنید.
  4. اسکریپتی بنویسید که هر فایل .log در /tmp را بشمارد و عدد را چاپ کند.
  5. چرا name = "Ali" غلط است ولی name="Ali" درست؟

پاسخ‌ها:

پاسخ ۱

#!/bin/bash → echo "$(date)" "$USER" "$(ls ~ | wc -l)"

پاسخ ۲

if [ -f "$1" ]; then echo "hast"; else echo "nist"; fi

پاسخ ۳

for i in 1 2 3 4 5; do mkdir /tmp/b$i; done → سپس: for i in 1 2 3 4 5; do rmdir /tmp/b$i; done

پاسخ ۴

echo "logs: $(ls /tmp/*.log 2>/dev/null | wc -l)"

پاسخ ۵

در انتساب فاصله باعث می‌شود bash فکر کند name یک «دستور» است — انتساب باید چسبیده باشد.

چالش‌های مرتبط

«شیفت شب»، «تعقیب زمان» و «پاسخ‌گوی شب» اسکریپت‌هایی دارند که باید بخوانید و بفهمید.
