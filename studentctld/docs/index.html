📖 آموزش کوتاه HTML

همین تگ‌های ساده کافی است تا اولین صفحه وب خود را بسازید!

HTML چیست و به چه دردی می‌خورد؟

HTML (زبان نشانه‌گذاری ابرمتن) اسکلت هر صفحه وب است. وقتی سایتی را باز می‌کنید، مرورگر کدهای HTML را می‌خواند و آن را به متن، تصویر، پیوند و جدول تبدیل می‌کند.

  • ساخت یادگیری‌اش ساده است؛ فقط یک ویرایشگر متن و یک مرورگر لازم دارید.
  • هر سایتی که بازدید می‌کنید — از کوچک تا بزرگ — بر پایه HTML ساخته شده است.
  • پایه‌ی یادگیری کارهای بزرگ‌تر است: بعداً CSS برای زیبایی و جاوااسکریپت برای تعامل اضافه می‌شود.

تگ‌های مهم و پرکاربرد

HTML از تگ تشکیل شده؛ بیشتر تگ‌ها جفت هستند: تگ باز و تگ بسته:

<p>این یک پاراگراف است</p>
تگکاربرد
<!DOCTYPE html>به مرورگر می‌گوید این سند HTML5 است
<html>ریشه‌ی صفحه؛ همه‌ی تگ‌ها داخل آن قرار می‌گیرند
<head>اطلاعات پشت‌صحنه (عنوان، انکودینگ) — دیده نمی‌شود
<title>عنوانی که روی زبانه‌ی مرورگر نمایش داده می‌شود
<body>محتوای اصلی که بازدیدکننده می‌بیند
<h1> تا <h6>سرتیترها؛ h1 بزرگ‌ترین است
<p>پاراگراف متن
<a>پیوند؛ با ویژگی href به آدرس مقصد
<img>تصویر؛ با src (مسیر فایل) و alt (متن جایگزین)
<ul> / <ol> / <li>فهرست نقطه‌ای / شماره‌دار و هر مورد آن
<strong> / <em>متن مهم (توپر) / تأکید (کج)
<br>رفتن به خط بعد؛ تگ بسته ندارد

مثال: صفحه‌ی معرفی خودتان

با همین تگ‌ها می‌توانید یک صفحه‌ی «درباره من» بسازید. کد زیر را در فایلی با نام index.html ذخیره کنید:

<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="utf-8">
  <title>درباره من</title>
</head>
<body>
  <h1>علی دانش‌آموز</h1>
  <p>سلام! من به وب و برنامه‌نویسی علاقه دارم.</p>

  <h2>علایق من</h2>
  <ul>
    <li>ساخت صفحه وب</li>
    <li>کار با لینوکس</li>
    <li>ریاضی</li>
  </ul>

  <img src="my-photo.jpg" alt="عکس من" width="200">

  <p><strong>تماس:</strong>
     <a href="mailto:ali@example.com">ali@example.com</a></p>
</body>
</html>
📝 تمرین: همین کد را بردارید، متن‌ها را به اطلاعات خودتان تغییر دهید و فایل را با نام index.html در پوشه‌ی ~/public_html/ حساب لینوکسی‌تان ذخیره کنید. بعد از چند لحظه، صفحه‌ی شما روی آدرس وب خودتان در دسترس خواهد بود!

برای دیدن نتیجه می‌توانید فایل را مستقیماً در مرورگر باز کنید: در فایرفاکس یا کروم کلید Ctrl+O را بزنید و فایل را انتخاب کنید.
