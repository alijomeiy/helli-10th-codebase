🔐 آموزش دسترسی‌ها

روی سرورِ مشترک، هر فایل یک قفل دارد: چه کسی می‌تواند بخواند، بنویسد، اجرا کند؟

چرا اصلاً دسترسی‌ها وجود دارند؟

سرور شما یک خانه‌ی مشترک است: ده‌ها کاربر روی همین یک سیستم حساب دارند. دسترسی‌ها تضمین می‌کنند که رازهای شما مال شما بماند و کسی جز مدیر سیستم (root) به همه‌چیز دسترسی داشته باشد.

هر فایل سه‌تاییِ دسترسی دارد برای سه گروه: مالک (owner)، گروه (group) و بقیه (others).

خواندن خروجی ls -l

-rw-r----- 1 ali students  4096 Aug 28 10:30 secret.txt
│├──┤├──┤├──┤   │        │
│ │   │   └── others: r--      (فقط خواندن)
│ │   └────── group:  r--      (فقط خواندن)  → توجه: این نمونه r-- است
│ └────────── owner:  rw-      (خواندن + نوشتن)
└──────────── نوع: - فایل، d پوشه

هر سه‌تایی فقط سه حرف است: r خواندن، w نوشتن، x اجرا/ورود — و خط تیره یعنی «این یکی را ندارد».

rwx برای فایل و پوشه فرق دارد!

حرفروی فایلروی پوشه
rخواندن محتوا (cat)دیدن لیست نام‌ها (ls)
wتغییر محتوا (vim و ذخیره)ساخت/حذف فایل داخل آن (touch, rm)
xاجرا کردن (./script)ورود به آن (cd) و رسیدن به فایل‌هایش
نکته‌ی طلایی: پوشه‌ای با --x را نمی‌توانید ls کنید، اما اگر نام دقیق فایل داخلش را بدانید می‌توانید cat کنید! پوشه‌ی r-- را لیست می‌کنید ولی واردش نمی‌شوید.

chmod عددی: سه رقم، هر رقم از ۰ تا ۷

هر حرف یک عدد است: r=4، w=2، x=1 — و هر سه‌تایی جمعِ آن‌ها:

عددمعنیمثال استفاده
7rwx (۴+۲+۱)اسکریپت‌های خودتان: chmod 700 setup.sh
6rw- (۴+۲)فایل متنی معمولی
5r-x (۴+۱)خواندنی + قابل ورود
4r-- (فقط خواندن)چیزهای مهم که نباید تغییر کنند
0هیچ چیزی!قفل کامل — نه خواندن، نه نوشتن، نه ورود

معروف‌ترین ترکیب‌ها:

chmod 644 file.txt   # شما: rw-  بقیه: r--      (فایل معمولی)
chmod 600 secret.txt # شما: rw-  بقیه: هیچ      (راز شخصی)
chmod 755 script.sh  # شما: rwx  بقیه: rx       (اسکریپت عمومی)
chmod 000 locked.txt # قفل کامل

chmod نمادین: فقط یک بخش را عوض کن

chmod u+x run.sh     # به مالک x اضافه کن
chmod go-r notes.txt # از گروه و بقیه r را بگیر
chmod a=r file.txt   # همه دقیقاً فقط r داشته باشند  (a = همه)

u مالک، g گروه، o بقیه، a همه؛ + اضافه، - گرفتن، = دقیقاً تنظیم کن.

chown: تغییر مالک

chown lab file.txt        # مالک becomes lab
chown lab:students f.txt  # مالک و گروه با هم

فقط root می‌تواند مالک را به کس دیگری بدهد — در آزمایشگاه (mybox) که root هستید آزادید؛ روی سرور مشترک فقط مدیر.

چه کسی اجازه‌ی chmod دارد؟ مالکِ فایل! لازم نیست فایل قابل‌خواندن باشد که دسترسی‌اش را عوض کنید — فقط باید مالکش باشید. یعنی حتی یک فایل 000 هم اگر مال شماست، با chmod 644 باز می‌شود.

تمرین

  1. خروجی -rwxr---— را به عدد تبدیل کنید.
  2. چه دستوری فایل note.txt را فقط برای مالک قابل‌خواندن می‌کند (۶۰۰)؟
  3. پوشه‌ی box با chmod 000 قفل شده؛ با چه دستوری فقط برای خودتان قابل‌ورود می‌شود؟
  4. فرق chmod 644 و chmod 600 روی فایل چیست و کدام برای «راز شخصی» درست است؟
  5. در خروجی ls -l چه چیزی جای d ابتدای خط می‌نشیند و یعنی چه؟
