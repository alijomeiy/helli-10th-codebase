🗜️ آموزش آرشیو و فشرده‌سازی

در لینوکس همه‌چیز را «بسته‌بندی» می‌کنند — یاد بگیرید بازش کنید.

چرا آرشیو؟

دو مفهوم جدا داریم: آرشیو یعنی چند فایل/پوشه را در «یک فایل» جمع کردن (مثل tar)، و فشرده‌سازی یعنی کم‌حجم کردن (مثل gzip). ترکیب همیشگی لینوکس: tar + gzip که پسوندش می‌شود .tar.gz.

tar در همه‌جا نصب است — روی سرور و در آزمایشگاه شما. ابزار دیگری لازم ندارید.

باز کردن (پرکاربردترین کار شما!)

tar xzf file.tar.gz          # باز کردن در پوشه‌ی فعلی
tar xzf file.tar.gz -C /tmp  # باز کردن داخل پوشه‌ی دیگر
tar xf file.tar              # آرشیوی که فشرده نیست
gunzip file.gz               # فقط فایل فشرده‌ی تکی

کلیدها: x = extract، z = gzip، f = file. ترفند حفظ‌کردن: «eXtract Ze File».

قبل از باز کردن: نگاه داخل بسته

tar tzf file.tar.gz          # فهرست محتوا (t = list) بدون باز کردن
tar tzf file.tar.gz | head   # فقط ۱۰ خط اول

همیشه اول t بزنید — هم می‌فهمید داخل چیست، هم می‌فهمید آرشیو پوشه دارد یا فایل‌های لخت؛ بعضی آرشیوها موقع باز کردن همه‌جا را شلوغ می‌کنند!

ساختن آرشیو

tar czf out.tar.gz folder/        # کل پوشه را بسته‌بندی کن
tar czf out.tar.gz a.txt b.txt    # چند فایل
gzip bigfile.txt                  # فایل تکی را فشرده می‌کند (اصل حذف می‌شود!)
gzip -k bigfile.txt               # فشرده کن ولی اصل را نگه دار

کلیدها: c = create، z = gzip، f = نام خروجی. ترتیب f مهم است: بلافاصله بعد از f، نام فایل می‌آید.

فرمت‌های دیگر که می‌بینید

پسوندباز کردن
.tar.gz / .tgztar xzf
.tar.bz2tar xjf (j = bzip2)
.tar.xztar xJf (J = xz)
.tartar xf
.gz (تکی)gunzip یا zcat

ترفند طلایی: file mystery.bin نوع واقعی هر فایلی را می‌گوید — حتی اگر اسمش دروغ بگوید. (روی سرور نصب است؛ در آزمایشگاه بخشی از سیستم پایه است.)

آرشیو و داکر

آرشیو فقط برای فایل نیست! تصویرهای داکر هم «فایل tar» هستند: docker save تصویر را tar می‌کند و docker load برمی‌گرداند. و خودِ tar هم از داخل، لایه‌های بیشتری می‌تواند داشته باشد — آرشیوِ داخل آرشیو کاملاً رایج است.

تمرین (در آزمایشگاه خودتان انجام دهید)

  1. پوشه‌ی /etc/cron.d را به /tmp/cron-backup.tar.gz آرشیو کنید — بدون باز کردن، اول محتوایش را فهرست کنید.
  2. آرشیو تمرین ۱ را در /tmp/restored باز کنید و مطمئن شوید فایل‌ها سر جایشان‌اند.
  3. تفاوت tar czf و tar xzf در یک خط بگویید.
  4. فایلی به نام notes.gz دارید؛ بدون فشرده‌گشایی، محتوایش را ببینید.
  5. یک آرشیو بسازید که داخلش یک آرشیو دیگر باشد و بعد هر دو لایه را باز کنید.

پاسخ‌ها:

پاسخ ۱

tar tzf /tmp/cron-backup.tar.gz (اول!) و بعد: tar czf /tmp/cron-backup.tar.gz /etc/cron.d

پاسخ ۲

mkdir -p /tmp/restored && tar xzf /tmp/cron-backup.tar.gz -C /tmp/restored

پاسخ ۳

c می‌سازد (create)، x باز می‌کند (extract)؛ z یعنی gzip و f یعنی نام فایل.

پاسخ ۴

zcat notes.gz

پاسخ ۵

tar czf outer.tar.gz inner.tar.gz && tar xzf outer.tar.gz && tar xzf inner.tar.gz
