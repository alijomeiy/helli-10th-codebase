🐳 داکر ۱۰۱ داخل آزمایشگاه

کانتینر = یک برنامه با همه‌ی وسایلش، بسته‌بندی‌شده. حالا خودت بساز!

داستان از زبان خودتان

شما داخل آزمایشگاهتان (mybox) هستید — که خودش یک کانتینر است. حالا داکر داخلش نصب است: یعنی می‌توانید کانتینرِ داخل کانتینر بسازید! مفاهیم اصلی:

  • تصویر (image): قالبِ از پیش ساخته — مثل سیدی نصب
  • کانتینر (container): یک نمونه‌ی «روشن‌شده» از تصویر
  • ریجستری: فروشگاه تصویرها — docker pull از آنجا می‌کشد

اولین کانتینر

docker run hello-world     # معروف‌ترین تست دنیا
docker run -it busybox     # یک لینوکس مینیاتوری! (i=interactive, t=terminal)
exit                       # خروج = کانتینر می‌ایستد

busybox یک لینوکسِ خیلی کوچک است — برای تمرین بی‌نظیر است.

لایف‌سایکل: چهار فعل

docker ps -a        # همه‌ی کانتینرها (حتی خاموش‌ها) — بدون -a فقط روشن‌ها
docker run -d --name web nginx          # -d=پس‌زمینه، --name=اسم گذاشتن
docker logs web     # خروجی/لاگ کانتینر
docker exec -it web bash                # ورود به داخل کانتینرِ در حال اجرا
docker stop web     # خاموش
docker rm web       # پاک کردن کانتینر خاموش
docker rmi nginx    # پاک کردن تصویر

پورت و حجم

docker run -d -p 8080:80 --name myweb nginx
curl localhost:8080      # سایت nginx — از پورت ۸۰۸۰ داخلِ box شما!

-p 8080:80 یعنی: پورت ۸۰ کانتینر را روی پورت ۸۰۸۰ آزمایشگاهم باز کن. و برای نگه‌داشتن فایل‌ها بین کانتینرها: -v /opt/lab/www:/usr/share/nginx/html (پوشه‌ی من → داخل کانتینر).

تصویر خودت بساز: Dockerfile

یک فایل به نام Dockerfile بسازید:

FROM busybox
CMD ["echo", "Az khabit midam!"]

بعد:

docker build -t myfirst:1 .    # نقطه = این پوشه
docker run myfirst:1           # خروجی: Az khabit midam!

لایه‌ها: راز تصویرها

هر خط Dockerfile یک لایه می‌سازد. لایه‌ها مثل حلقه‌های پیاز روی هم می‌روند و — نکته‌ی مهم — حذف در لایه‌ی بعدی، چیزی را از لایه‌های قبلی پاک نمی‌کند! این دلیل است که تصویرها با docker save که به tar تبدیل می‌شوند، گاهی رازهای «حذف‌شده» را هنوز دارند. تاریخچه را ببینید:

docker history myfirst:1

تمرین (در آزمایشگاه خودتان انجام دهید)

  1. با busybox یک فایل در کانتینر بسازید: docker run -it busybox بعد داخلش echo hi > /tmp/x — بعد exit و دوباره run کنید؛ فایل هست؟ چرا؟
  2. nginx را با -p 8080:80 بالا بیاورید و با curl امتحان کنید.
  3. با docker exec وارد کانتینر nginx شوید و صفحه‌ی پیش‌فرض را عوض کنید (فایل index.html).
  4. Dockerfile بسازید که تصویری با نام greet:1 بسازد و اسم شما را چاپ کند.
  5. چرا docker rm برای کانتینر روشن خطا می‌دهد؟

پاسخ‌ها:

پاسخ ۱

نه — هر run یک کانتینر تازه از تصویر می‌سازد؛ تغییرات کانتینر قبلی با آن کانتینر ماند (تا rm شود).

پاسخ ۲

docker run -d -p 8080:80 nginx → curl localhost:8080

پاسخ ۳

docker exec -it web bash → echo Salam > /usr/share/nginx/html/index.html

پاسخ ۴

FROM busybox / CMD ["echo", "Ali"] → docker build -t greet:1 .

پاسخ ۵

اول باید stop شود (فرایند زنده دارد)؛ با -f می‌شود اجبار کرد.
