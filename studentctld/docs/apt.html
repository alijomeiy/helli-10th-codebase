📦 آموزش apt — نصب نرم‌افزار در لینوکس

در لینوکس نصب برنامه از «دانلود و next-next» راحتر است: یک دستور، تمام.

apt چیست؟

apt مدیریت بسته‌ی اوبونتو است: از مخزن‌های (repository) معتبر، برنامه‌ها را با همه‌ی پیش‌نیازهایش دانلود، نصب و به‌روز می‌کند. مخزن شما همان مخزنِ سرور است (آینه‌ی ایرانی، سریع).

دسترسی نصب فقط برای root است — یعنی روی سرورِ مشترک نمی‌توانید، اما در آزمایشگاه خودتان که root هستید آزادید.

دستورهای پایه

دستورکار
apt updateفهرست بسته‌ها را تازه می‌کند (قبل از هر نصب!) — چیزی نصب نمی‌کند
apt install pkgنصب بسته (مثلاً apt install tree)
apt remove pkgحذف بسته (فایل‌های تنظیم می‌ماند)
apt purge pkgحذف کامل + تنظیمات
apt search wordجستجوی نام بسته
apt show pkgاطلاعات بسته: نسخه، حجم، توضیح
apt upgradeبه‌روزرسانی همه‌ی بسته‌های نصب‌شده
قانون طلایی: اول apt update، بعد apt install. اگر update نزنید ممکن است بسته پیدا نشود یا نسخه‌ی قدیمی نصب شود.

پس از نصب: بسته کجا رفت؟

dpkg -L tree          # فهرست همه‌ی فایل‌هایی که بسته‌ی tree گذاشت
dpkg -S /usr/bin/vim  # کدام بسته این فایل را گذاشته؟

این دو دستور برای چالش‌های «بسته‌ی مرموز» به دردتان می‌خورد...

نصب از فایل deb محلی

گاهی بسته را به‌صورت فایل .deb دارید (بدون مخزن):

apt install ./kit.deb     # با apt (پیش‌نیازها هم حل می‌شود)
dpkg -i kit.deb           # یا با dpkg

ترفندهای کاربردی

apt list --installed | grep -i json   # بسته‌های نصب‌شده‌ی مرتبط
apt install tree jq htop              # چند بسته با هم
apt install -y tree                   # بدون پرسیدن yes/no (برای اسکریپت)

تمرین (در آزمایشگاه خودتان انجام دهید)

  1. تفاوت apt update و apt upgrade چیست؟
  2. چه دستوری نشان می‌دهد بسته‌ی jq وجود دارد و توضیحش چیست، بدون نصب؟
  3. ابزار tree را نصب کنید و ببینید فایل‌هایش کجا نصب شده‌اند.
  4. بسته‌ای را که در تمرین ۳ نصب کردید، کامل (با تنظیمات) حذف کنید.
  5. چرا apt install روی سرور مشترک برای شما خطای دسترسی می‌دهد ولی در mybox کار می‌کند؟

پاسخ‌ها:

پاسخ ۱

update فقط فهرست/مخزن را تازه می‌کند؛ upgrade خودِ بسته‌های نصب‌شده را به نسخه‌ی جدید می‌آورد.

پاسخ ۲

apt show jq

پاسخ ۳

apt install tree && dpkg -L tree

پاسخ ۴

apt purge tree

پاسخ ۵

چون فقط root اجازه‌ی نصب دارد؛ روی سرور کاربر عادی‌اید ولی در mybox root هستید.

حالا در CTF، چالش‌های دسته‌ی «آسان» را باز کنید — به همین‌ها وابسته‌اند.
