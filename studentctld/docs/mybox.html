🧪 راهنمای آزمایشگاه شخصی (mybox)

یک لینوکس کامل و خصوصی که در آن root هستید — آزادانه نصب، اجرا و حتی خراب کنید.

آزمایشگاه چیست؟

تا امروز روی سرور فقط یک «اتاق در خانه‌ی مشترک» داشتید: حساب محدودی که نمی‌توانست نرم‌افزار نصب کند و به همه‌جای سیستم دسترسی نداشت.

آزمایشگاه، خانه‌ی خودتان است: یک اوبونتوی کامل و ایزوله که فقط شما واردش می‌شوید و در آن root هستید — یعنی مدیرِ مطلق. هر کاری در آن بکنید فقط به خودتان ربط دارد.

ورود به آزمایشگاه

اول مثل همیشه به سرور وصل شوید، بعد فقط یک کلمه تایپ کنید:

ssh yourname@62.3.41.38        # مثل همیشه
mybox                          # داخل آزمایشگاه خودتان
root@box-yourname:/#           # شما root هستید!
exit                           # برگشت به حساب معمولی

اولین کار: نصب ابزارها

آزمایشگاه عمداً خالی است! ابزارها را خودتان نصب کنید — این همان تمرین است:

apt update                     # به‌روزرسانی فهرست بسته‌ها
apt install vim tree curl      # نصب ابزارها
apt install python3 iproute2   # پایتون و ابزار شبکه (ss)

درس کامل apt: 📖 آموزش apt

کانتینر (داکر) داخل آزمایشگاه

دستور docker آماده است — می‌توانید تصویرها را بکشید و اجرا کنید:

docker pull nginx
docker run -d -p 8080:80 nginx
curl localhost:8080            # سایت خودتان داخل جعبه!
docker images                  # فقط تصویرهای خودتان اینجاست

هر آزمایشگاه داکرِ مخصوص خودش را دارد؛ تصویرهای بقیه برای شما دیده نمی‌شود و برعکس.

قوانین زندگی در آزمایشگاه

موضوعتوضیح
خواب خودکاربعد از ~۳۰ دقیقه بی‌کاری آزمایشگاه می‌خوابد (رمز آزاد می‌شود). دفعه‌ی بعد mybox بزنید — همه‌چیز سر جایش است.
محدودیت منابعهر آزمایشگاه حداکثر ~۳۸۴MB رم و نیم‌هسته پردازنده دارد؛ بیش از آن، فرایندهای خودتان متوقف می‌شوند.
بازنشانیاز پنل (بخش «آزمایشگاه من») می‌توانید آزمایشگاه را از نو بسازید. همه‌چیز پاک می‌شود و از اول نصب کنید.
حریم خصوصیداده‌ی مهم/شخصی داخل آزمایشگاه نگذارید؛ این محیط تمرین است و ممکن است بازنشانی شود.
خروج از آزمایشگاهدستور exit شما را به حساب معمولی سرور برمی‌گرداند.
چالش‌های آزمایشگاه: در تابلوی CTF، دسته‌ی «آزمایشگاه» و سطوح «آسان / سخت / بسیار سخت» پرچم‌هایی دارند که داخل همین آزمایشگاه شما پنهان شده‌اند — و پرچم هر نفر مخصوص خودش است!

سؤالات رایج

mybox زدم، خطای sudo داد؟ یک بار از سرور خارج و دوباره وارد شوید (عضویت گروه با ورود جدید فعال می‌شود).

حجم/رمز آزمایشگاه من چیست؟ رمز همان رمز SSH شماست؛ داخل باکس root هستید و رمز نمی‌خواهد.
