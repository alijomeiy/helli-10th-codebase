HTML چیست؟

HTML (Hyper Text Markup Language) زبان نشانه‌گذاری ابرمتن - اسکلت هر صفحه وب است. وقتی سایتی را باز می‌کنید، مرورگر کدهای HTML را می‌خواند و آن را به متن، تصویر، پیوند و جدول تبدیل می‌کند. در واقع بخشی از وب روی کامپیوتر کاربر و بخشی از آن روی سرورها اجرا می‌شود!

چند مورد درباره HTML:

  • HTML مانند یک زبان برنامه‌نویسی منطق اجرایی ندارد و تنها برای نمایش است، بنابراین نسبت به آن‌ها ساده‌تر است.
  • هر سایتی که بازدید می‌کنید — از کوچک تا بزرگ — بر پایه HTML ساخته شده است.
  • HTML اسکلت هر صفحه است و با CSS و JavaScript به ترتیب رنگ‌ها و جلوه‌های هنری و انیمیشن‌ها یا کارکردهای دیگر اضافه خواهد شد، این دو نیر بخش مهمی از دنیای وب هستند اما فعلا در بحث ما نیستند.

تگ‌های مهم و پرکاربرد

HTML از تگ تشکیل شده؛ بیشتر تگ‌ها جفت هستند: تگ باز و تگ بسته اما گاهی هم یک تگ به تنهایی استفاده می‌شود، تگ‌ها توضیح ساده‌ای هستند از این که آن محتوا درباره چیست، مثلا: Document 

<p>این یک پاراگراف است</p>
تگ کاربرد
<!DOCTYPE html> به مرورگر می‌گوید این سند HTML5 است
<html> ریشه‌ی صفحه؛ همه‌ی تگ‌ها داخل آن قرار می‌گیرند
<head> اطلاعات پشت‌صحنه (عنوان، انکودینگ) — دیده نمی‌شود
<title> عنوانی که روی زبانه‌ی مرورگر نمایش داده می‌شود
<body> محتوای اصلی که بازدیدکننده می‌بیند
<h1> تا <h6> سرتیترها؛ h1 بزرگ‌ترین است
<p> پاراگراف متن
<a> پیوند؛ با ویژگی href به آدرس مقصد
<img> تصویر؛ با src (مسیر فایل) و alt (متن جایگزین)
<ul> / <ol> / <li> فهرست نقطه‌ای / شماره‌دار و هر مورد آن
<strong> / <em> متن مهم (توپر) / تأکید (کج)
<br> رفتن به خط بعد؛ تگ بسته ندارد

مثال: صفحه‌ی معرفی

با استفاده از همین کد ساده‌ای که در زیر آمده شروع به ساختن کنید، آن را در مسیر مورد نظر کپی کنید و تلاش کنید تکمیل و اصلاحش کنید 

<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="utf-8">
  <title>درباره</title>
</head>
<body>
  <h1>سهراب رستم</h1>
  <p>اگر مرگ داد است، بی‌داد چیست؟ / ز داد این همه بانگ و فریاد چیست؟.</p>

  <h2>علایق من</h2>
  <ul>
    <li>اسب‌سواری</li>
    <li>شکار</li>
    <li>جنگ با شمشیر</li>
  </ul>
