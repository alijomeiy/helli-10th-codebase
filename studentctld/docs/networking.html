🌐 آموزش شبکه

آدرس‌ها، پورت‌ها و حرف‌زدن با سرویس‌ها — از داخل آزمایشگاه خودتان.

IP و پورت: آدرس و شماره‌ی در

هر ماشین در شبکه یک IP دارد (آدرس ساختمان). روی هر ماشین پورت‌ها شماره‌های ۱ تا ۶۵۵۳۵ هستند (واحدهای ساختمان)؛ هر سرویس (وب، ssh، ...) گوشِ یکی از این پورت‌ها است. localhost / 127.0.0.1 یعنی «خودم» — تلفن داخلی ساختمان.

ابزارهای این درس در آزمایشگاهِ لخت نصب نیستند — اول نصب‌شان کنید (این هم بخشی از تمرین است):

apt update && apt install iproute2 curl

آدرس من چیست؟

ip a                    # کارت‌های شبکه + IP ها (eth0 معمولا کارت اصلی است)
ip r                    # مسیرها؛ با gateway پیش‌فرض

چه پورت‌هایی باز است؟

ss -tlnp                # همه‌ی پورت‌های Listen + فرایند صاحبشان
ss -tlnp | grep :80     # فقط پورت ۸۰
# t=tcp  l=listening  n=عددی  p=process

این مهم‌ترین دستور کارآگاهی شبکه است: هر سرویس پنهانی، اینجا خودش را لو می‌دهد — مگر اینکه فقط روی localhost گوش بدهد!

curl: حرف زدن با سرویس‌ها

curl http://localhost:8080          # بگیر و نشان بده
curl -s http://example.com          # بی‌حرف (silent)
curl -i http://localhost:9999       # هدرهای پاسخ را هم نشان بده
curl -H "X-Token: abc123" http://localhost:8080   # با هدر سفارشی
curl -o page.html http://x.ir       # در فایل ذخیره کن

پورت‌ها را زنده دیدن

وقتی سرویسی را بالا می‌آورید (مثلاً python3 -m http.server 8080) می‌توانید با ss ببینید که واقعا گوش می‌دهد و با curl امتحانش کنید:

python3 -m http.server 8080 &
ss -tlnp | grep 8080
curl http://localhost:8080

کارت شبکه آزمایشگاه شما

آزمایشگاه شما شبکه‌ی خصوصی خودش را دارد (به آن شبکه‌ی پل‌شده می‌گویند): از داخل می‌توانید به اینترنت برسید (apt کار می‌کند) اما دنیای بیرون نمی‌تواند مستقیم به پورت‌های شما وصل شود — یعنی فضای تمرین امن دارید.

نکته: ping در کانتینر ممکن است کار نکند (نیاز به مجوز خاص دارد) — نگران نشوید؛ با curl و ss همه‌ی کارهای این درس انجام می‌شود.

تمرین (در آزمایشگاه خودتان انجام دهید)

  1. IP کارت شبکه‌ی آزمایشگاه را پیدا کنید.
  2. قبل از نصب iproute2 دستور ss را بزنید — پیام خطا چیست و چرا؟
  3. یک وب‌سرور ساده روی پورت ۸۰۸۰ بالا بیاورید و با curl جوابش را ببینید.
  4. با ss ثابت کنید سرویس تمرین ۳ روی ۸۰۸۰ گوش می‌دهد، بعد بکشیدش.
  5. به سایت مستندات کلاس با curl -s سر بزنید و عنوان صفحه را بگیرید.

پاسخ‌ها:

پاسخ ۱

ip a → به دنبال inet در eth0 بگردید (مثلاً 10.0.2.100)

پاسخ ۲

bash: ss: command not found — چون iproute2 نصب نیست؛ در اوبونتوی لخت همه‌چیز از اول نصب نیست.

پاسخ ۳

python3 -m http.server 8080 & (python3 را اگر ندارید: apt install python3) بعد: curl localhost:8080

پاسخ ۴

ss -tlnp | grep 8080 → kill %1

پاسخ ۵

curl -s https://docs.helli-10th-computer.ir/ | grep -o '<title>.*</title>'
