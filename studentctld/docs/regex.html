🔎 آموزش کوتاه ریجکس (Regex)

با چند علامت ساده، بین هزاران خط متن فقط چیزی را پیدا کنید که می‌خواهید.

ریجکس چیست و به چه دردی می‌خورد؟

ریجکس (عبارت باقاعده) یک زبان کوچک برای توصیف شکلِ متن است. به‌جای اینکه بگویید «دنبال این کلمه بگرد»، می‌گویید «دنبال هر متنی بگرد که این شکلی است».

  • مثلاً «هر چیزی که مثل شماره تلفن است» یا «هر پرچمی که دقیقاً دو حرف و دو رقم دارد».
  • ابزار آشنا با آن کار می‌کند: grep -E 'الگو' فایل
  • در خیلی از زبان‌های برنامه‌نویسی، ادیتورها و حتی جست‌وجوی vim هم همین الگوها کار می‌کنند.

علامت‌های مهم

علامتمعنیمثال
abc متن دقیق FLAG فقط همین کلمه
. هر کاراکتری F.AG ← FLAG و FXAG و ...
[abc] یکی از این حرف‌ها b[ae]t ← bat یا bet
[a-z] هر حرف کوچک انگلیسی b[a-z]t ← هر bt با یک حرف وسط
[0-9] یک رقم b[0-9]t ← b7t
{2} دقیقاً ۲ تای قبلی [a-z]{3} ← سه حرف کوچک پشت هم
{2,4} ۲ تا ۴ تای قبلی [0-9]{2,4} ← 42 یا 123 یا 1234
* صفر یا بیشترِ قبلی ab* ← a یا ab یا abbbb
+ یک یا بیشترِ قبلی ab+ ← ab یا abbb (حداقل یکی)
^ ابتدای خط ^err ← خطی که با err شروع شود
$ انتهای خط flag$ ← خطی که به flag ختم شود
| یا cat|dog ← cat یا dog
\{ خودِ کاراکتر { (خنثی‌کردن معنی ویژه) FLAG\{ ← دقیقاً FLAG{

چطور با grep استفاده کنم؟

برای الگوهای ریجکسی، از grep -E استفاده کنید:

grep -E 'الگو' نام‌فایل

مثال ۱: پرچمی با شکل مشخص

فرض کنید پرچم واقعی این شکل را دارد: دو حرف کوچک، خط تیره، دو رقم — مثل FLAG{ab-12}. پس الگو می‌شود:

grep -E 'FLAG\{[a-z]{2}-[0-9]{2}\}' decoys.txt

یعنی: حرف‌به‌حرف FLAG{ بعد دقیقاً دو حرف کوچک، بعد -، بعد دقیقاً دو رقم، بعد }

مثال ۲: فقط خط‌هایی که از اول خط با err شروع می‌شوند

grep -E '^err' anchor.log

بدون ^، هر خطی که err هر جایش باشد پیدا می‌شود — با ^ فقط آن‌هایی که از ابتدا شروع می‌شوند.

تمرین

📝 تمرین: در حساب لینوکسی خودتان پوشه‌ی ctf/regex/ را ببینید. دو فایل تمرین ریجکس آنجا منتظر شما هستند! با الگوهایی که یاد گرفتید فقط خطِ درست را پیدا کنید.

نکته: داخل vim هم می‌توانید با / و همین الگوها جستجو کنید.
